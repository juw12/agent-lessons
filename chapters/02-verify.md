# Verification, tests and gates

201 lessons. Most-repeated first.

- (mise, 2026-11) Never kill browsers with Get-Process headless_shell | Stop-Process: other sessions share the machine and their Playwright runs die too (and so did my own detached checker, which then hung silently). Kill only your own tree: find children by ParentProcessId of your checker PID. Make long checkers print a flushed progress line per phase so a hang is visible.
- Voice in PWAs: never rely on Web Speech alone (missing in Firefox, silent in iPhone home-screen apps). Keep a recorder + server STT fallback, enforce limits with timers (not audio callbacks), and test with a real WAV through Chromium's fake mic (one fresh browser per scenario). Playwright's Windows WebKit has no getUserMedia or AudioContext, so stub them to emulate iOS.
- `D report` must survive one slow site: a 180 s audit timeout used to abort the whole report (batam-uncle-says, 2026-11-07); it now records 'audit timed out' and moves on. Sessions run in parallel: re-check paths (the skill folder was renamed refine -> hone mid-run) and re-run gates right before publishing.
- A project that moved needs its CTA links changed in `state/content/<slug>.json` **and** the stored `state/data.json` entry (ingest refuses rebuilt pages). Declare the old->new pairs in `MOVED_LINKS` in `tools/check.py` so G3 accepts the move.
- When a council finding claims a race or crash bug, prove it with a real reproduction (a real kill, a real NFS mount, a real protected branch) before and after the fix; simulated tests found none of the bugs the real ones did.
- Local Playwright checkers on Windows: use ThreadingTCPServer and end with `os._exit()` after writing results; a single-threaded server plus browser.close()/server.shutdown() hung for minutes after the work was done.
- Long council/test runs: launch with creationflags DETACHED_PROCESS so a Python-tool timeout or restart does not kill them; poll the output files.
- Local and live audits gave identical counts for Cairn, so baseline/after both on the local checkout is a fair comparison.
